## Sobre o Projeto

Este repositório contém a entrega da Atividade Prática - Parte II da disciplina de Modelagem e Projeto de Banco de Dados, ministrada pelo Professor Romes. 

O objetivo do projeto é aplicar os conceitos de DDL (Data Definition Language) na construção de um esquema completo de banco de dados. O cenário simula o sistema de informação de uma clínica médica, contendo 10 tabelas relacionais com suas devidas chaves, restrições e relacionamentos.
